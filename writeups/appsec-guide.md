# Application Security & Engineering (AppSec)

A **Cybersecurity Specialist** is responsible for securing software, web applications, and APIs beyond traditional infrastructure defense. This discipline focuses on remediating code-level vulnerabilities, minimizing the attack surface, and implementing a Secure Software Development Life Cycle (Secure SDLC).

## 2. Core Technical Areas & Workflow

- **OWASP Top 10 Vulnerabilities:** Preventing critical risks such as Injection (SQLi), Broken Authentication, and Server-Side Request Forgery (SSRF).
- **Threat Modeling (STRIDE):** Systematically analyzing design-phase risks such as spoofing, elevation of privilege, and information disclosure.
- **Security Testing (SAST/DAST):** Early vulnerability detection using source code analysis and dynamic testing tools (e.g., Burp Suite, SonarQube).
- **API & Web Service Security:** Protecting REST and GraphQL endpoints against authorization flaws like Broken Object Level Authorization (BOLA) and Broken Function Level Authorization (BFLA).

## 3. Summary of Technical Competencies

- **Protocol Analysis:** Inspecting HTTP/2, WebSocket, and TLS encryption mechanisms.
- **Input Validation:** Preventing injection attacks through parameterized queries and strict data sanitization techniques.
- **Secure Architecture:** Implementing the Principle of Least Privilege (PoLP) and multi-layered authentication integration.
